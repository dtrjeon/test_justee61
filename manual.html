전도일 입력 & 주차 자동 설정
상단 📅 전도일 날짜 선택 → 주차가 자동 계산됩니다. 필요시 주차 드롭다운에서 직접 수정 가능.
전도일을 먼저 입력해야 문서번호가 자동생성됩니다.
1
조 선택 & 팀 구성원
  • 조 선택: 드롭다운에서 내 조 번호 선택
  • 복음제시 구분: 관계(팀) / 질문지(팀) / 7일후(팀) / 개인 / 관계 / QQ 중 선택
  • 횟수: 해당 주차 몇 번째 복음제시인지 입력
  • 훈련자(조장) / 훈련자 / 훈련생: 이름 입력
💡 프리셋 활용 👤 버튼에서 내 조 프리셋을 저장해두면 매번 입력 불필요.
2
통계 입력
항목설명입력
접촉횟수현장에서 만난 모든 사람 수직접 입력
복음제시복음을 제시한 횟수직접 입력
전도대상복음을 제시받은 대상자 수직접 입력
결신 / 보류 / 확신 / 이미신자진단 결과별 인원5번 후 자동반영
결신·보류·확신·이미신자는 5번 항목(진단)에서 자동 집계. 수동 입력 시 수치가 2 이상이면 제출 경고.
3
만난 분의 인적 정보
  • 관계: 대상자를 모신 분(팀원) 선택
  • 대상자 구분: 지인/가족/지구촌교인/질문지/7일후/훈련생 중 선택
  • 거주지역: 예) 신봉동 | 성씨: 예) 전씨 | 나이: 예) 35세
  • 결혼여부: 미혼/기혼 | 성별: 남자/여자
  • 만난 장소: 예) 수지성전, 카페
  • 복음전달: 대면 / 비대면
📷 OCR 버튼으로 공개보고서 용지를 촬영하면 일부 항목이 자동 인식됩니다.
4
종교 배경 & 직업
  • 종교배경: 기독교/천주교/불교/무교 선택. 기타는 직접입력 후 + 목록에 등록
  • 직업: 자유 텍스트 입력
5
확신 및 이유 질문 — 진단 핵심 ⭐
5-1 천국 확신: 있었고 / 없었고
5-2 이유 대답: 믿음(예수님) / 행위 / 불확실 / 대답안함
확신이유 대답진단영접결과
있다믿음머리신자/이미신자영접 or 불필요결신/이미신자
있다행위·불확실·대답안함착각비신자영접 or ✕결신/보류
없다믿음확신부족/비신자확신 or ✕확신/보류
없다행위·불확실·대답안함비신자영접 or ✕결신/보류
5-1, 5-2 선택 → 🎯 진단 결과 자동 계산. 영접 여부 선택 → 통계 자동 반영.
6
개인간증 반응 (확신 있음 + 믿음)
이미신자 / 머리신자 선택 — 확신 있음 + 믿음인 경우에만 활성화
7
개인간증 반응 (확신 없음 + 믿음)
확신부족신자 / 비신자 선택 — 확신 없음 + 믿음인 경우에만 활성화
8
역할 배분
훈련자(조장) / 훈련자 / 훈련생 각각:
  • 맡은 역할: 서론, 은혜, 인간, 하나님, 그리스도, 믿음, 즉석양육 중 해당 부분
  • 행동: 하였고 / 참관하였고 / 불참하였고
개인전도 시: 전도한 분만 [하였고], 나머지는 [불참하였고] 선택 필요.
9
즉석양육 & 후속양육
  • 즉석양육: 했고 / 안했고
  • 후속양육: 24시간 이내 전화 / 예배 참석 약속 / 7일 후 재방문 / 새가족반 연결 / 하지 못함
  • 하지 못한 경우 → 사유 입력
10~13
느낀점 / 문제점 / 기도제목 / 기타
  • 10번: 성령께서 인도하신 특별한 경험 (교훈)
  • 11번: 현장전도에서 문제점/개선점
  • 12번: 요청받은 기도제목
  • 13번: 기타

OCR 자동입력 기능
손으로 쓴 공개보고서를 찍으면 자동 인식
📌 OCR 기능이란?현장에서 손으로 작성한 공개보고서 용지를 스마트폰으로 촬영하면, OCR.space API가 문자를 인식해 앱 폼에 자동으로 입력해줍니다. 모든 항목이 인식되지 않을 수 있으므로 인식 후 반드시 확인 및 수정이 필요합니다.
📷 OCR 사용 절차 — 단계별 안내
1
3번 항목(인적정보) 위의 📷 카메라 아이콘 버튼을 탭합니다.
2
카메라 또는 갤러리에서 공개보고서 용지 사진을 선택합니다.
※ 밝고 선명하게, 글씨가 잘 보이도록 촬영할 것
3
상태 표시: ⏳ OCR 문자 인식 중... → 🧠 인식된 텍스트 분석 중...
완료 시 ✅ 자동입력 완료! (N개 항목 인식) 메시지
4
🔍 OCR 인식 결과 확인 패널에서 파싱된 필드값 테이블 확인.
📄 OCR 인식 원문 보기로 원본 텍스트 확인 가능.
5
잘못 인식된 항목은 직접 수정. 인식 못한 항목(종교배경, 직업 등)은 수동 입력.
✅
잘 인식되는 항목
나이, 성씨, 거주지역, 결혼여부, 성별, 만난장소, 진단결과 등 선명하게 쓴 텍스트
⚠️
인식이 어려운 경우
흐리거나 기울어진 사진, 체크박스(□), 복잡한 표 구조. 이 경우 수동 입력 필요.
💡
촬영 팁
밝은 환경에서 정면으로 촬영. 그림자 없게. 용지 전체가 화면에 들어오도록. 손떨림 주의.
⚠️ 주의OCR 인식 후에도 반드시 전체 항목을 검토하세요. 일부 항목이 누락되거나 오인식될 수 있습니다.

❓
자주 묻는 질문 (FAQ)
문제 해결 가이드
Q1
이미 제출했는데 수정하고 싶어요
기록 탭에서 해당 보고서를 클릭해 불러온 뒤 수정 후 다시 제출하세요. 이전 이력은 보존되고 최신본이 모니터링에 표시됩니다.
Q2
통계(결신 등)가 자동 반영 안 돼요
5번 진단 항목에서 영접 여부 버튼(✅ 영접 / ❌ 보류·거부)을 반드시 선택해야 통계에 반영됩니다.
Q3
통계 수치 확인 필요 오류가 떠요
결신·보류·확신·이미신자 중 하나가 2 이상입니다. 5번 진단에서 자동반영된 값이 맞는지 확인하고 수정하세요.
Q4
OCR 인식이 잘 안 돼요
밝은 환경에서 정면으로 재촬영하세요. 인식 오류는 파싱된 필드값 테이블에서 확인 후 직접 수정하세요.
Q5
임상(A4) 탭이 안 보여요
👤 프리셋 → 앱 설정 → "임상 탭 표시" 토글을 ON으로 바꾸세요.
Q6
PDF 저장 시 A4로 인쇄돼요
브라우저 인쇄 다이얼로그에서 용지 크기를 A5(148×210mm)로 직접 선택하세요.
Q7
모니터링에서 데이터가 안 보여요
필터 바의 조 선택이 "전체"인지 확인 후 🔍 조회 버튼을 다시 눌러보세요. 또는 🔄 새로고침.
